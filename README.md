# TalentHub Careers — Practice Job Board

Separate practice website for the TalentHub Recruiters SEO internship. It is NOT the client's production site.

## Deploy
1. Extract the ZIP.
2. Create a NEW GitHub repository named `talenthub-practice-job-board` (do not reuse Oak & Elm).
3. Upload all files/folders to the repository root.
4. Import that repository in Netlify; publish directory `.` and no build command.
5. Replace every `https://YOUR-SITE.netlify.app/` with your actual Netlify URL in canonical tags, robots.txt and sitemap.xml before crawling.

## Included
1 homepage, 1 all-jobs hub, 5 category pages, 15 job pages, 4 information pages, CSS, JavaScript, robots, sitemap, redirects, audit matrix, crawl plan and decision log. Each category page has four working filters and eight controlled crawlable filtered links.

Important: several technical issues are deliberately seeded for practice. Verify each with Screaming Frog/source evidence before reporting. Do not describe practice-site findings as defects on the client's real website.
